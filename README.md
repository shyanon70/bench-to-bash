# Bench to Bash

Daily shell, HPC, Git and genomics-workflow practice (QC, RNA-seq, ChIP-seq, single-cell) for bioinformatics beginners.
Installable app (PWA): works offline after the first visit.

## Files
- `index.html` - the whole app
- `sw.js` - offline cache (bump `VERSION` after every change)
- `manifest.webmanifest`, `icons/` - name and home-screen icon

## Publish with GitHub Pages
1. Create a public repo named `bench-to-bash` on github.com.
2. Upload these files (or `git add . && git commit -m "First version" && git push`).
3. Settings -> Pages -> Source: "Deploy from a branch", branch `main`, folder `/ (root)` -> Save.
4. After about a minute the app is live at `https://<your-username>.github.io/bench-to-bash/`.

## Install on your phone
- iPhone/iPad: open the link in Safari -> Share -> Add to Home Screen.
- Android: open the link in Chrome -> menu -> Install app.
